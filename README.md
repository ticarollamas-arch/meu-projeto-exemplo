# Meu Projeto Publicado via ZipToGit

Este projeto foi compactado em .ZIP e publicado **espontaneamente** diretamente para o GitHub através do **ZipToGit**.

## Recursos
- Publicação instantânea usando GitHub Git Data API
- Suporte a blobs binários e texto
- Filtros inteligentes para ignorar node_modules e arquivos confidenciais
